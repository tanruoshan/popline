# Why your marks matter

Your rectangles become the **gold standard** of the study. You mark before any system has produced output, and you never see what the systems found, so your marks are independent of them. That is what makes the comparison fair. For the same reason, please mark from reading the page, without searching for words like "Europa" with Ctrl+F. Judge from the page image itself, even where the scan looks hard for a computer to read.

# The task in one sentence

On each page in your folder, draw a rectangle around every article that deals with the idea of European unity or cooperation, or that names Europe in passing, and add a short note to each rectangle.

# The two main rules

**Rule 1: the topic decides, not the word.** An article counts as IDEA because of what it is about, not because of the words it uses. A text arguing for cooperation among European states is IDEA even if the word "Europa" never appears (for example only "the continent", "the nations of the West" or "Briand's proposal"). If you mark something as IDEA and it does not contain Europe or Paneuropa, add `implicit` to the note.

**Rule 2: one article, one number, one note.** Each article gets one number, and that number is the unit we count. Draw one rectangle per column the article runs over, all with the same number and the same note. Please do not draw a separate rectangle for each mention inside an article. An article gets the highest grade that applies: if one paragraph is IDEA, the whole article is IDEA. Include the headline in the rectangle.

# What counts

**IDEA**: the text discusses, as a topic, cooperation, union or a common order among European states or peoples. For example:

- Paneuropa, Coudenhove-Kalergi, the Pan-European Congress (Vienna, October 1926), local Paneuropa groups
- a European federation, a "United States of Europe", a European customs union, Briand's plan
- Europe as a community with a shared fate (for example "the European crisis", Europe facing America or Russia), when that is a theme of the text and not just a word
- international conferences (Locarno, the League of Nations, The Hague 1929), when the text treats them as being about the order or unity of Europe. A report only about reparation sums or dates does not count.

**MENTION**: the text names Europe, Paneuropa, Coudenhove-Kalergi, the Briand plan or similar in a recognisable way, but is about something else. For example "the best hotel in Europe", a travel report, a news item listing Coudenhove-Kalergi among guests, a book advertisement. These are worth marking because a keyword search finds them.

**Not relevant**: everything else, including vague allusions in a text about something else. No rectangle needed.

**Pages with nothing relevant**: a sticky note anywhere on the page with the word `NONE` (in Acrobat: *Add a comment → Sticky note*). This tells us the page was read and is empty, which is different from not yet read. It matters most in tier 3, where most pages will probably be empty.

# Stance (only for IDEA)

Stance toward the idea of European unity or cooperation itself (not toward a person, a country or a conference). One stance per article.

| Code | Meaning |
|---|---|
| PRO | the text supports or welcomes it, or presents it as desirable or necessary |
| CONTRA | the text rejects, mocks or warns against it |
| NEUTRAL | a report without a judgement, or balanced pro and contra |
| UNSURE | hard to decide; a word on why helps us later |

The voice that counts is the text's, not that of the people it quotes: a neutral report of a pro-Europe speech is still NEUTRAL (you can add `speech`). If an article is for European unity but against a specific actor (for example "yes to Europe, but not under French leadership"), PRO plus `against:France` captures it.

# Drawing and labelling (Adobe Acrobat Reader, free)

1. Open the PDF and choose the **rectangle** tool among the comment or drawing tools (in newer versions: *All tools → Add a comment → Draw rectangle*).
2. Drag a rectangle around the article, headline included. If it runs over two columns, draw one rectangle per column with the same article number.
3. Double-click the rectangle's border (or right-click → *Open Pop-up Note*) and type the note.
4. Save with **Ctrl+S**, keeping the file name. Please avoid "print to PDF" or flattening; the rectangles need to stay editable for the computer to read them.

Other PDF tools (Foxit, Xodo, Okular, PDF-XChange) work too, as long as they make rectangle annotations with a note. The browser's built-in PDF viewer (Edge, Chrome) cannot do this.

# What is needed, and what is welcome

To keep this quick, only four things are **needed**. Everything else is **welcome when it comes naturally**, and fine to skip when time is short.

| Needed | Welcome, optional |
|---|---|
| grade: `IDEA` or `MENTION` | `borderline`, `speech`, `reprint`, `against:X`, `cont:` |
| stance for IDEA: `PRO`, `CONTRA`, `NEUTRAL` or `UNSURE` | a smaller second rectangle around the IDEA part of a long article (see below) |
| `implicit` when an IDEA article does not contain Europe or Paneuropa | a line in the chat about unclear cases |
| `NONE` sticky note on pages with nothing relevant | |

# Note format (the computer reads this part)

```
A<number> <GRADE> [<STANCE>] [tags] [comment]
```

- `A1 IDEA PRO`
- `A2 MENTION`
- `A3 IDEA CONTRA implicit`
- `A4 IDEA UNSURE ironic?`
- `A5 IDEA PRO against:France`
- `A6 IDEA NEUTRAL speech`
- `A7 MENTION reprint`
- `A8 IDEA NEUTRAL borderline maybe only geography`
- `A9 IDEA PRO cont:T1-04/A3`
- `NONE` (sticky note on an empty page)

Numbering starts again at A1 in each file. Upper or lower case both work. Tags can come in any order after the stance; anything else is kept as a free comment. If a note does not follow the format, the code lists it and we ask you, so nothing is lost.

| Tag | When to use it |
|---|---|
| `implicit` | IDEA without the word Europe or Paneuropa in the text (Rule 1). **Needed.** |
| `borderline` | you are unsure whether it is IDEA, MENTION or not relevant; a few words why help |
| `speech` | the article mainly reports a speech; the stance is still the text's own voice |
| `reprint` | you notice you have seen the same item (e.g. an event announcement) before; mark every copy as usual |
| `against:X` | PRO toward European unity, but against a specific actor or country X |
| `cont:<pack id>/A<n>` | only when it is obvious that the article continues from another file, e.g. `cont:T1-04/A3` (the pack id is the start of the file name). Within one file, just reuse the same number |

**Long articles (optional).** If an article is longer than about half a column and only part of it is IDEA, you can add a second, smaller rectangle around the IDEA part, with the same number and the same note. It sharpens one of our secondary measures, but the article rectangle alone is enough.

Tier 3 comes before tier 2 because these are the only pages nobody chose by keyword, so they show how rare the topic really is. Please send each folder back (zipped, in the WhatsApp group) as soon as it is done, so the computing can start while you continue.

# Unclear cases

Very welcome. Tag them `borderline` or `UNSURE` in the note, and if you like, add a quick line in the chat (file, article number, why). They become the "how hard is relevance" paragraph in the paper.
